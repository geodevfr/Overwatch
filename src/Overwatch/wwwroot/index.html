Réglages

Les conditions du jeu peuvent interdire un outil tiers, même s'il ne fait qu'observer. Overwatch ne lit pas le programme, ne le modifie pas, et ne cherchera pas à échapper à un contrôle ajouté plus tard. L'usage reste le vôtre.

Noms que le jeu cherche

Souvent nécessaires pour que le client passe par ici. Le nom est celui que le jeu demande. La redirection est un bloc # >>> overwatch >>> écrit seulement pendant l'observation, puis retiré. Sans droits administrateur, l'observation démarre quand même et cette page le dit : le jeu ne passera pas par ici. Overwatch ne change pas les permissions du fichier hosts.

      Captures

      La capture copie les octets après le relais. Elle n'ajoute aucun délai au jeu. Une lecture de 16 384 octets est le plein du tampon réseau, pas un message du protocole. Les deux sens doivent contenir quelque chose. Si le début ressemble à TLS, le contenu reste illisible : Overwatch ne le déchiffre pas.

      Versions du client

      Aucune signature n'est active tant que la version est inconnue. On ne devine pas les codes de messages : ils changent à chaque mise à jour, et ils ne vivent que dans la table de détection.
