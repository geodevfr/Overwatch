      Captures

      La capture copie les octets après le relais. Elle n'ajoute aucun délai au jeu. Une lecture de 16 384 octets est le plein du tampon réseau, pas un message du protocole. Les deux sens doivent contenir quelque chose. Si le début ressemble à TLS, le contenu reste illisible : Overwatch ne le déchiffre pas.

      Versions du client

      Aucune signature n'est active tant que la version est inconnue. On ne devine pas les codes de messages : ils changent à chaque mise à jour, et ils ne vivent que dans la table de détection.
